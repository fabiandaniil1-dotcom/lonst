# Eventu — бронювання квитків на університетські події

Статичний фронтенд-проєкт без збірки та залежностей: відкривається подвійним кліком по `index.html`
або будь-яким статичним сервером. Дані (акаунти, броні, відгуки) зберігаються в `localStorage`.

## Структура

```
eventu/
├── index.html              # головна: афіша, локації, відгуки, всі модалки
├── admin.html              # адмінпанель: події, броні, відгуки, акаунти
├── assets/
│   ├── css/style.css       # уся стилізація, світла й темна теми
│   └── js/
│       ├── config.js       # налаштування (мова за замовчуванням, ліміт квитків, контакти)
│       ├── data.js         # події, локації, початкові відгуки
│       ├── i18n.js         # рядки інтерфейсу UA / EN
│       ├── store.js        # localStorage: акаунти, броні, відгуки, місця
│       ├── app.js          # рендеринг і вся логіка головної сторінки
│       └── admin.js        # логіка адмінпанелі
├── pages/                  # про проєкт, як це працює, FAQ
├── legal/                  # обробка даних, умови, cookies, канал звернень
└── README.md
```

## Запуск

Найпростіше:

```
open index.html          # macOS
start index.html         # Windows
```

Або локальним сервером (рекомендовано, щоб коректно працювали відносні посилання):

```
python3 -m http.server 8080
# http://localhost:8080
```

## Що вміє

- афіша з фільтрами за категоріями та пошуком за назвою / локацією;
- картки-квитки з лічильником вільних місць і генерованими постерами (SVG, без зовнішніх зображень);
- реєстрація та вхід поштою або через Google (Sign in with Google);
- ліміт квитків на акаунт (`config.js → maxTicketsPerUser`);
- адмінпанель окремою сторінкою: створення та редагування подій, скасування броней, експорт CSV/JSON;
- бронювання з підтвердженням, кодом квитка та розділом «Мої квитки» зі скасуванням;
- інтерактивна карта кампусу з пʼятьма локаціями;
- відгуки з оцінкою в зірках;
- дві мови (UA / EN), світла й темна теми, банер cookies;
- адаптивність від 320 px, видимий фокус із клавіатури, підтримка `prefers-reduced-motion`.

## Вхід через Google

1. Google Cloud Console → **APIs & Services → Credentials → Create credentials → OAuth client ID**.
2. Тип: **Web application**. У *Authorized JavaScript origins* додайте домен, з якого відкривається
   сайт (наприклад `http://localhost:8080` для локального запуску та ваш робочий домен).
3. Скопіюйте Client ID у `config.js`:

```js
google: {
  clientId: '1234567890-abc.apps.googleusercontent.com',
  allowedDomain: ''        // 'lnu.edu.ua' — приймати лише університетську пошту
}
```

Поки `clientId` порожній, кнопка не показується, а в модалці входу видно підказку — решта входу
поштою працює як звичайно. Google-вхід не працює з `file://`: потрібен http-сервер (див. «Запуск»).
Токен від Google розбирається на клієнті лише для демонстрації; у робочій версії його треба
перевіряти на сервері.

## Адмінпанель

Відкривається за адресою `admin.html`. Вбудований доступ (задається в `config.js → admin`):

```
admin@eventu.university / eventu2026
```

Доступ мають лише акаунти, чия пошта є у списку `admin.emails`. Коли адміністратор увійшов,
посилання на панель зʼявляється у верхньому рядку сайту.

Що вміє панель:

- показники: кількість подій, квитків, очікувана каса, середня заповненість, акаунти, відгуки;
- **Події** — створення, редагування (дві мови, дата, ціна, місця, кольори постера) та видалення
  разом із бронями; пошук за назвою;
- **Броні** — пошук за кодом, імʼям або поштою, скасування, експорт у CSV;
- **Відгуки** — видалення доданих відвідувачами;
- **Система** — список акаунтів, експорт усіх даних у JSON, скидання каталогу подій до `data.js`.

Зміни з панелі одразу видно на головній сторінці: обидві сторінки читають один і той самий
каталог із `localStorage`.

## Як змінити контент

- **Додати подію** — новий об'єкт у `EVENTU_DATA.events` (`data.js`). Обовʼязкові поля:
  `id`, `cat`, `venue`, `date`, `duration`, `price`, `seats`, `taken`, `ink`, `paper`, `ua`, `en`.
  Кольори `ink` / `paper` визначають згенерований постер.
- **Додати категорію** — у `EVENTU_DATA.categories`, далі використати її `id` у полі `cat` події.
- **Змінити тексти інтерфейсу** — `i18n.js`, ключі однакові для обох мов.
- **Змінити палітру** — CSS-змінні в `:root` та `html[data-theme="dark"]` у `style.css`.

## Підключення справжнього бекенда

`store.js` — єдине місце, що працює зі сховищем. Замініть тіла `register`, `login`, `book`,
`cancel`, `addReview` на `fetch()` до вашого API, а `data.js` — на завантаження подій з сервера.
Решта коду залишиться без змін.

## Обмеження

Навчальний проєкт: автентифікація відбувається в браузері й не є захищеною, онлайн-оплати немає
(квитки оплачуються на вході), дані живуть лише в поточному браузері.
